# Run Claude with the power of Local LLMs using Ollama

## Install Ollama
### paste this in PowerShell
`irm https://ollama.com/install.ps1 | iex`

## Install Claude
### paste this in PowerShell
`irm https://claude.ai/install.ps1 | iex`

## Run Claude with Ollama
`ollama launch claude`
